## 中版（LOFTER、博客）

**能用的搜索引擎 · 网易云版**

起因很简单：Poppin'Party 的「キラキラだとか夢だとか ～Sing Girls～」，库里至少有三个原唱版本，但网易云把原唱排到两百多条结果的最后三位。第一屏全是伴奏版、网友翻唱和无关内容。

这个工具做三件事：搜集数据、建立本地索引、按你自己的规则排序展示。只保留网易云搜索（歌名 / 歌词 / 专辑 / 歌手 / 歌单 / 播客），能看音质、VIP、原唱标注、发行时间，能按音质排序、按年份筛。

纯 Python 标准库，零第三方依赖，Windows 双击 `install.cmd` 就能跑，macOS / Linux 用 `install.sh`。

https://github.com/kipp546IO/usable-search-engine-NECM

MIT 许可，随便改。
