# 更新日志

## v0.1.0（2026-11-02）

首个公开版本（哔哩哔哩版）。功能见 README「功能一览」。

**相对内部开发版的整理**
- 只发布 B 站这一侧：界面、文档、截图、示例都按 B 站重写。
- 内部过程记录（状态交接、回归抽样、问题清单）不进公开仓。
- 本机绝对路径改为占位符；提交署名统一为 noreply 邮箱。
- `pyproject.toml` 清掉早期草稿残留的依赖声明（fastapi / uvicorn / jieba），实际实现只用标准库。
- 补「下载即用」说明、一键安装脚本与 MIT 许可。

**这一版做到的事**
- 六种搜索维度：综合 / 名称 / 简介 / 标签 / UP主 / UID。
- 时长与发布时间筛选；七种排序（综合 / 综合热度 / 最新 / 最旧 / 播放量 / 弹幕 / 收藏）。
- 四档匹配标准：标准 / 标准·不含标签 / 严格（仅标题）/ 宽松（不过滤）。
- 命中位置可见：每张卡片标出命中标题、简介还是标签。
- 档案与下架复查：查不到不判死，网络异常单独归类。
- 备份站直链（默认关闭，只发 HEAD、1 秒间隔、命中永久缓存）。
- 接口可用性探针：成功率与 p50 / p95，风控单独计数。
- 深色模式、结果内二次筛选、搜索历史、清缓存面板、分页 30 / 50 / 100 / 300。

**已知限制**
- 抓的是非官方接口，风控按 IP，低频使用；被 `-352` 挡时会提示稍后再试。
- 首次搜索要现场扫多页，冷门关键词会慢几秒。
- 名称 / 简介 / 标签的匹配是本地后筛，平台接口本身不提供这些检索能力。
- 只做桌面浏览器形态；手机版在计划里，还没做。
